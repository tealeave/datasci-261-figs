# W261 final project figures

Figures for the DATASCI 261 Phase 3 report, hosted here so the report can reference them by
public raw URL. Nothing else lives in this repo.

Each PNG is pre-sized to the width it should display at, because Databricks markdown carries no
width attribute and the report references them as `![alt](raw URL)`.

| figure | subject |
|---|---|
| fig17, fig18 | blind-2019 leaderboard at a 25% alert budget; validation against blind |
| fig19, fig22 | the feature repair compared against the choice of model family |
| fig20, fig21 | the two leakage defects: the gate that failed open, and coverage restored |
| fig23, fig24 | why F2 is read at a fixed alert volume rather than at its own maximum |
| fig25, fig26 | entity-embedding network architecture and its two design rules |
| fig27, fig28 | the extra-credit network against the four required families; training curves |
| fig31, fig32 | TreeSHAP on both feature tables; the turnaround dependence plot |
| mlp_val, xgboost_blind | MLP validation curves and the XGBoost blind threshold sweep |
